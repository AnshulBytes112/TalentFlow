## Known Issues

### 1️⃣ Application Submission on Draft Jobs
- **Severity**: LOW (expected behavior)
- **Issue**: Cannot apply to draft jobs
- **Fix**: Publish job first: `PATCH /api/jobs/{jobId}/publish`
- **Impact**: No impact - proper workflow

2. Run `node qa-runner.js` to verify
3. Check console logs in running terminal
4. File issue with endpoint and error details

**Want to Extend Tests?** Edit `qa-runner.js`:
- Add new test cases in `runAPITests()` function
- Add UI tests in `runUITests()` function
- New bugs are automatically logged
